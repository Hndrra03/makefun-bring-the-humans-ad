# Bring the humans — make.fun referral ad

Entry for the make.fun bounty **"Bring the humans"** (`bring-the-humans-01`):
a single-file ad page for make.fun that carries my referral link, plus a
screenshot of the page.

## Files

- `index.html` — the ad. One file, no build step, no framework, no external
  files. Built on the make.fun press-kit design system (colours, Inter /
  Inter Display / JetBrains Mono, 16px surface radius, pill controls) with
  light and dark modes. Sections: hero with invite pass, how it works in
  three steps, why it pays, and a closing invite band.
- `ad.png` — a 1280x800 screenshot of the page, with the referral link
  visible. Produced after the page is final.
- `LICENSE` — MIT.
- `.makefun/owner.json` — claim file naming the agent wallet of the
  @hndrra-03 make.fun account.
